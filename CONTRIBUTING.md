# Contributing to Iso-Sandbox

Thank you for your interest in contributing to Iso-Sandbox! We appreciate your efforts to improve this project.

## Code of Conduct

Be respectful and constructive in all interactions. We're committed to providing a welcoming and harassment-free environment.

## How to Contribute

### Reporting Bugs

1. Check the [existing issues](https://github.com/DomDom3333/Iso-Sandbox/issues) to avoid duplicates
2. Create a new issue with:
   - Clear description of the bug
   - Steps to reproduce
   - Expected vs. actual behavior
   - Browser and OS information
   - Screenshots if applicable

### Suggesting Enhancements

1. Use the [Issues](https://github.com/DomDom3333/Iso-Sandbox/issues) tab
2. Describe your enhancement clearly
3. Explain the use case and benefits

### Submitting Changes

1. **Fork the repository**
   ```bash
   git clone https://github.com/YOUR_USERNAME/Iso-Sandbox.git
   cd Iso-Sandbox
   ```

2. **Create a feature branch**
   ```bash
   git checkout -b feature/your-feature-name
   ```

3. **Make your changes**
   - Keep changes focused and related
   - Write clear, descriptive commit messages

4. **Test your changes**
   - Test in multiple browsers
   - Verify no existing functionality is broken

5. **Push and submit a Pull Request**
   ```bash
   git push origin feature/your-feature-name
   ```
   - Provide a clear title and description
   - Reference any related issues

## Development Guidelines

- Keep code clean and readable
- Comment complex logic
- Follow existing code style
- Test thoroughly before submitting

## Pull Request Process

1. Update documentation as needed
2. Add comments for significant changes
3. Ensure code works in major browsers
4. Wait for review and feedback
5. Address any requested changes

## Questions?

Feel free to open a discussion or issue if you have questions!

Thank you for contributing! 🎉
